## How to cite

If you use this reproducibility bundle or its results, please cite **both** the analysis pipeline DOI **and** the substrate dataset DOI.

### Analysis pipeline (this deposit)

```bibtex
@dataset{javvadi_defect_attribution_pipeline_2026,
  author    = {Javvadi, Vijay Prasad},
  title     = {Post-Execution Defect Attribution --- Reproducibility Bundle},
  year      = 2026,
  version   = {1.0.0},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.20723929},
  url       = {https://doi.org/10.5281/zenodo.20723929}
}
```
